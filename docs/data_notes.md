## Prices are synthetic

The ABO listings metadata contains no price field. To demonstrate price-based
filtering (e.g. "under $50"), ShopTalk assigns **simulated prices** to ABO products.

- **These prices are not real.** They do not reflect actual Amazon prices.
- Generated by `src/preprocess/synthetic_prices.py`: a log-normal distribution per
  product type, seeded from the item ID (deterministic and reproducible).
- Every row carries `price_is_synthetic = True`.
- Price is used only as a metadata filter and is never included in embedded text.
- Retrieval and generation quality results are therefore unaffected by price, and
  price-filter tests only evaluate the filtering logic, not real-world pricing.
