# ShopTalk

A shopping assistant that finds products from natural-language queries using
Retrieval-Augmented Generation (RAG). Supports text input now, with voice input planned.

## Project structure
- `data/` – raw and processed data -“Amazon Berkeley Objects (ABO), Amazon.com, CC BY 4.0”
- `notebooks/` – Colab experiments and fine-tuning
- `src/` – preprocess, embeddings, vectordb, captioning, rag, api, ui, voice
- `eval/` – test queries and evaluation scripts
- `docs/` – charter, architecture, results
